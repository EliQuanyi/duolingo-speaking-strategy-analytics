## 按优先级保留的选择与输入

以下事项先进入规划，不在本轮提问或自动执行。每一项只放行对应路线，未通过的结论继续保持未知。

### 1. 后续新增发布渠道、展示信息与许可（路线 A）

- **原因 / 默认暂停影响**：新增公开渠道、联系资料和License会改变展示范围与再使用条件。本轮GitHub发布已经授权并执行；其他渠道与新许可暂缓，不影响现有仓库发布。
- **所需输入**：后续个人作品页、学校提交或其他展示的选择；新增学校/联系信息的范围；是否采用新License及其适用文件。第三方资料许可须逐项独立遵守。
- **确认后步骤 / Gate / 停止点**：按渠道裁剪已审核发布清单，复核敏感信息和第三方再分发边界，保留版本与复现说明；内容和许可一致后才发布。发布后记录地址与版本，不声称公司合作、试验成绩或未经验证的收益。

### 2. 是否开展外部真人研究及资源安排（路线 B）

- **原因 / 默认暂停影响**：招募、联系参与者、采集录音/评分或使用付费资源需要明确授权。默认不联系、不招募、不采集、不付费；保留可审查预案，不阻塞路线 A。
- **所需输入**：研究用途与负责人、可接触的自愿人群、合法访问条件、招募渠道；适用的学校/机构审批或豁免依据、知情同意、数据保存/访问/删除安排；可用评分资源和获批准的支出范围。
- **确认后步骤 / Gate / 停止点**：先核资格与访问，再选择观察、鼓励或同剂量路线；完成同意文本与数据契约，试核任务/随访可行性，查看正式结果前冻结方案。无法全员随访时保留缺测限制；处理或评分不匹配时退回任务观察。未经许可不分享参与者材料。

### 3. 当前权益与公司实施权限（路线 C；S4G01–02）

- **原因 / 默认暂停影响**：公开覆盖陈述不能确定目标账户是否真有新增权益，也不授予随机配置权。默认不发放或变更权益；只保留条件设计，不阻塞路线 A/B。
- **所需输入**：同日期、课程/母语、地区、设备/版本、个人套餐下的资格快照和真实 P0；明确的合作授权范围、配置与分配记录、责任人、对照可行性及恢复机制。
- **确认后步骤 / Gate / 停止点**：先区分既有权益和候选新增，核合法对照、处理/分配单位与曝光记录，再锁定一个政策问题。无真实增量停止当前 P1 定义；无实施权限停在交接，不将外部研究改称权益 RCT。

### 4. 学习测量、匹配基线与成功准则（路线 B/C；S4G03、08）

- **原因 / 默认暂停影响**：现有研究和自选评论不能决定新研究的样本、窗口或业务门槛。默认只保留[实验方案](../experiments/test_plan.md)的一个 primary，不承诺精确样本量、时间或成果。
- **所需输入**：与实际处理/人群匹配的前测与延后未练任务、盲评/平行任务校准、方差和缺测信息、最小有意义增益的依据、学习与课程/质量护栏；经营路线另需计费成熟依据。
- **确认后步骤 / Gate / 停止点**：先校准平行任务并避免共享测试题库；自然对话仍可能碰到题目，须预设盲核、重合敏感度与迁移解释边界，不能事后删分或换题。确认全员随访和评分可靠性，据匹配数据规划 N/MDE/窗口；业务受益门槛另由量表意义和批准投入决定，结果前冻结。人群或处理改变则重估；无匹配基线停在可行性/设计，无法解释未练迁移则不放行学习论证，不沿用旧成绩或VOC比例。

### 5. 完整经济数据、传播、部署范围与预算（路线 C；S4G04–07）

- **原因 / 默认暂停影响**：缺少这些输入会阻塞盈利、总体排序与商业 Scale。默认只运行符号核算，不出批准预算、收益金额或赢家；学习研究可在独立批准的资源范围内继续。
- **所需输入**：同窗原分配全员的两臂完整贡献与服务成本，含零使用、退款/费用、失败/重试/回退；实际合同/账单与遥测；原 Max 及其他受影响层的政策曝光/结果；同资格总体的分层部署 N、权重、新增 F、容量约束与批准预算。
- **确认后步骤 / Gate / 停止点**：按[Stage4 方法](../quant/evidence_assumptions.md)分别核两臂、原层和共同窗口；贡献与成本不重扣，全员差不再乘采用率。传播设计、各层效果与部署分母对应同一政策后才评价总体净值。缺层不补零，Super 单层不外推原 Max；未匹配完整成本、贡献、N/F 与传播时停止总体经营判断。教学投资可另按真实预算审定，不称盈利。
