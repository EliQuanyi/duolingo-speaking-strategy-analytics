**整理版本：closeout-v1.1（Stage4证据约束v2 + Stage5设计v1；正式文稿final-v1.0）｜整理：2026-10-03｜产品证据截止：2026-10-02｜作者：独立外部分析项目。** 本轮优化阅读、完整预算表述与复现验收，不新增产品观测或效果估计。

## 结论与行动

**H1中级英语学习任务值得验证；现有证据不能判定扩张盈利或选出权益策略赢家。**竞品已经提供课程与AI对话，下一步应比较未练情境的迁移、有效练习和完整投入。先核目标账户的当前权益及真实增量；增量存在、有实施权限并冻结测量方案后，才可启动一个条件性试验。无增量则停止原政策定义；无平台权限时改为知情学习研究，重新定义处理与估计对象。

**对象与缩写**：H1优先研究日语母语学习者的中级英语口语任务，日本市场及当前账户条件仍待核实；母语不代替居住地、课程等级不代替实际口语水平。P0为真实现行权益，P1为候选Super新增访问，P2为候选Free有限试用；任务优先不等于已选P1扩张。

商业与逻辑交接是：**市场任务/替代方案 → 受限学习信号 → 公司经营背景及反证 → 真实政策增量 → 双臂完整核算 → 缺口/就绪 → 一主指标试验 → 条件决策/监控**。这条链明确哪些环节已经观测、哪些仍待验证；没有把链条写成已证明的因果路径。

## 阅读路径

先看商业报告/决策卡，再按需要查市场、经营与Stage4依据；执行者随后看实验/监控与[后续规划](NEXT_PHASE_PLAN.md)，复核者看[复现指南](REPRODUCTION_GUIDE.md)与字段/清单。无需通读历史过程才能使用本轮结论。

## 最小复核与版本

在解压包或仓库根目录，`python -B scripts/rebuild_package_tables.py`只读复算三张公司派生、四张v2派生、三行基数桥接及58图点。仅需Python标准库，复现起点是共享CSV。加`--rebuild`会重写这七张派生表；它不抓网页、不生成旧D情景、不恢复私人298条编码。

Notebook、文稿与监控的真实环境、只读/写入命令、已知降级与重建顺序集中在[复现指南](REPRODUCTION_GUIDE.md)，不再在各入口重复配置。本轮未安装新依赖。

`python -B scripts/build_final_data_package.py --check-only`校验ZIP CRC、清单成员、逐文件哈希，并在新目录解压后执行CSV复算和Stage4独立验证。普通构建命令不带`--check-only`，从已审核白名单重新冻结；输入/报告更新后须重新验收再出新版本。仓库`scripts/verify_final_delivery.py`检查全部文件、页数、来源/主键、验收哈希和包内复现。

当前收束冻结为**81文件、25张CSV**，包版本v1.1新增阶段状态、复现指南与后续规划，未新增数据观测。复核范围是七张派生表、三行基数桥接、58图点、Stage4八组独立方法检查和原始验收哈希。冻结包未含私有原始评论、第三方全文或历史D经济/选择情景；它不能独立重建私人298条编码或网页采集过程。
