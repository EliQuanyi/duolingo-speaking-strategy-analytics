# 可复用经验

本页记录实际复核后可复用的方法经验，不记录临时任务状态。

- **PDF页脚按完整行和页码匹配**：逐页去除提取首尾的完整页脚，不能在拼接文本后以贪婪数字正则删除，否则会吞掉下一页数字标题。正文段落覆盖与视觉检查分别验收，不互相替代。依据：最终交付验收的页脚边界回归与同版Word/PDF核对。
- **冻结包不能只信自述清单**：哈希一致只能确认字节；还须将实际成员、版本、表契约与源码白名单比较，并在实际包内核查主要读者入口的相对链接。解压复算证明移交可运行，不认证来源真实性或因果。依据：最终数据包白名单边界回归、包内链接检查与独立目录复现。

- **预览与原生Office分别验收**：XLSX导出成功、渲染配色正确不能证明Excel条件格式生效；需用实际重算、DisplayFormat与图数据改动检查。许可失败的Save/PDF如实记录，可交最终文件同版渲染快照，但不能称原生打印通过；栅格正文不可搜索。依据：monitoring_design.md的实际导出修正与25个原生用例。
- **任务重合不事后挑选评分**：开放对话可能碰到未知测试场景；预设盲核、重合敏感度和解释边界，保留原组有效评分，无法解释未练迁移时不放行学习论证。依据：Stage5独立复核与test_plan.md。
- **冻包检验真实移交**：白名单不等于可运行，须解压到新目录执行最小复算，检查命令所需文件、字段名与图点来源；区分仓库历史审计和包内复现，避免拉入退休D模块。依据：最终数据包独立审阅与实际解压校验。

- **标注假设不等于合理估计**：可复现的作者参数只能说明方法，无校准域时不推现实收益、阈值或稳健赢家；正式证据包须明确隔离历史演示。依据：Stage4 v2复盘与生成链隔离验证。
- **最低充分数据优于填满参数表**：真实同窗两臂全员账单贡献和成本均值可直接结算；允许两臂不同，不必估所有潜在路径。未知不补零，源引用/软件声明不认证真实性或因果。依据：v2模型和独立边界检验。
- **有限补证也可以得到不可比结论**：公开订阅清单缺周期/账户类型/SKU时，不硬拼套餐溢价；日语L1、课程level、商店地区与当前账户资格分别审核。依据：v2公开补证及研究覆盖复算。

- **事实、样本和估计对象分别审核**：自选评论的真实性不等于代表性；多条观察/同源摘要不是独立样本；公司总体共时变化不能校准功能效果。依据：Stage2.1质量审阅、Stage3因果链复核。
- **先核实际增量再量化**：较新推出陈述可能覆盖旧产品说明；计划与已生效资格分别保存。已开放权益不能重复算新增，没有明确P0/增量时停实际建议。依据：Stage4政策证据与比较契约。
- **完整账单路径优于叠加漏斗收益**：升级/续订/降级不能各自重复计收入；全员效果不再乘采用率。赠送后付费调用与对照原有成本也须结算。依据：Stage4独立Decimal复算/概率守恒。
- **归一化不解决人群或固定费用缺口**：每千账户只放大变量贡献，不补总体权重、部署N或F/N。不同原套餐层的归一化值不能直接排总体赢家。依据：Stage4归一化边界检查。
- **条件阈值处理方向与可行性**：正/零/负工作量与边际贡献会改变或取消不等式；donor质量限制阈值是否可达。可复现D扫描只证明条件关系，不证明现实稳健或预测置信区间。依据：Stage4阈值独立代回和接口边界。
- **双臂均值不能静默沿用**：路径时点、退款、价格或工作量变化时，共享m/u失效，应改双臂完整路径或直接全员差值。降级不保证调用减少，方向须实测。依据：Stage4独立商业逻辑审阅。
