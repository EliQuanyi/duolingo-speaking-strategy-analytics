# Stage 2.1 市场与竞品证据补强标准

**版本：2026-09-29 规划版。当前只定标准与顺序，未完成补强分析。**适用于 Stage 2.1 的 VOC、竞品、市场机会与产品价值链；与 [`STAGE2_EVIDENCE_REFRESH.md`](STAGE2_EVIDENCE_REFRESH.md) 一起约束后续执行。既有 Stage 2 “降级通过”结论是起点，不因新增附件自动升级。

## 1. 唯一决策与研究单位

主问题仍是：**Duolingo 的 AI Speaking / Video Call 应先向谁、以何种权益扩大验证，哪些价值和风险值得投入实验？**研究单位固定为“用户任务 × 学习阶段 × 目标语言/地区 × 订阅权益 × 产品版本/时间”，而非把整个语言学习市场或所有评论合成一个平均用户。所有市场、竞品和 VOC 发现最终必须改变 H1 中级英语、H2 初学者引导或 H3 有限试用的**试验顺序、指标或护栏**。

候选比较保留 Duolingo 基准、Speak / ELSA / Babbel Speak 三个直接产品及 ChatGPT Voice / Preply 两个替代选择。若新证据证明某产品更贴近同一任务，可说明理由后在 3+2 名额内替换；不通过增加名单制造“深度”。不做全球 TAM、市场份额、远期 DAU 点预测或未经许可的跨平台总满意度排名。

## 2. 同场景的六维商业评审

每个维度以同一 H1/H2/H3 场景比较产品；单元格用“观察事实 / 提供方主张 / 用户自述 / 分析假设 / 未知”标记，不给缺乏同口径数据的产品打综合分。

| 维度 | 需要回答的比较问题 | 可记录的指标或证据 | 未知时交给哪一阶段 |
|---|---|---|---|
| 用户任务与可达覆盖 | 针对哪个语言、水平和使用时刻？地区、设备、课程、权益能否实际进入？ | 官方可用范围、版本与时间；资格、入口和首通失败的 VOC 反例 | Stage 5 资格/曝光埋点 |
| 学习机制与效果 | 是开放对话、引导任务、发音纠错还是真人辅导？反馈能否迁移到新情境？ | 脚手架/反馈事实、公开研究的设计与效应；有效开口、盲评转移任务的需求 | Stage 5 行为与独立测评 |
| 体验与信任 | 识别、打断、延迟、难度、隐私和可访问性是否阻断完成？ | 分平台 VOC 主题、反例、故障条件；有证据才记发生数 | Stage 5 质量护栏与分层 |
| 获取、激活与习惯 | 试用门槛、入口和课程整合是否促成首次及重复使用？ | 官方入口/试用规则；首通、有效完成、W1/W4 等待测指标 | Stage 5 随机试验 |
| 订阅与替代关系 | Max、Super、免费试用分别增加什么价值，会否替代升级或挤出课程练习？ | 官方权益/额度/价格的同地区同日期口径；转化、续费、Max 降级均保持未知 | Stage 4 阈值；Stage 5 实验 |
| 单位经济与可防御性 | 每有效口语分钟的 AI/辅导成本与差异化来源是什么？ | 官方成本披露仅按原口径使用；课程整合、内容供给、真人预约摩擦等事实 | Stage 4 情景、盈亏平衡 |

**商业价值链**：目标用户有未满足任务 → 看见并能进入功能 → 自愿完成有效口语练习 → 产生可测的学习收益 → 改变参与/留存/订阅选择 → 扣除 AI 成本、现有权益替代和质量损害后的净价值。每个箭头分别写“有证据 / 方向性信号 / 需实验”；不能用功能清单或公司总营收跨过中间环节。

## 3. 证据账本与可比性

后续建立**一条可核验主张一行**的 claim ledger，至少含 `claim_id,product,dimension,H1/H2/H3,region,language_level,tier,device_or_version,valid_as_of,claim_text,claim_kind,source_url,source_locator,source_date,accessed_on,evidence_grade,comparison_limit,verification_status`。原矩阵一行多结论共用多个 URL，只作发现索引，不作逐条证明。

- **A 官方披露**：可证明 Duolingo 当期业务或产品计划；公司因果/效果表述须标“公司称”。**B 独立研究或有方法的外部资料**：同时记录样本、对照、结果、外推范围。竞品官网、价格与帮助页只证明其当时的**供给与声明**，不证明学习效果或用户偏好。**C 自选 VOC/代理**：只用于发现机制和反例，按平台、采样框与产品分别报告。**D 情景/假设**：不得填入事实比较。
- 同一比较必须先固定用户任务、地区/币种、日期、设备、版本和权益。价格不同时区/币种/促销不可直接比较；未知写 `unknown`，不以推测补齐。
- 每条决策性比较给出来源定位、时间和口径；至少列一个反例或替代解释。样本内主题计数可以展示，但不得把 298 条自选评论当总体发生率、因果 uplift 或市场份额。
- 上传的 [`STAGE2_INPUT_INTAKE.md`](STAGE2_INPUT_INTAKE.md) 材料先标“待复核”。官方摘录逐条回到原页；用户摘要与标签在缺少原文、原始采样框和标签记录时不得升级为独立验证的直接体验。

VOC 质量报告需按平台、月份、帖子/评论、采样方法分别列出 `raw → 时间窗 → 关键词 → 去重 → 人工直接相关 → 第一人称` 的真实分母；另列空值、日期类型、单条 URL 比例、精确/近似去重及分层抽核分歧。Reddit 同一讨论帖中的多条评论按帖子聚类解释。若只审核关键词命中项，只能估计命中项准确性，**不能声称召回率**；若只有一位编码者，只记录单人复核与不确定项，不虚构编码者间一致性。平台覆盖不均时，月度帖子数不是用户需求趋势。

## 4. 执行顺序与交付

| 顺序 | 必要工作 | 收束物与停止条件 |
|---|---|---|
| 0 来源接收 | 保留文件哈希、合法使用/再分发判断，区分提供者说法与实际复核。 | `STAGE2_INPUT_INTAKE.md`；平台不准入时只保留允许的本地研究输入与方法，不向 public Git 上传整批记录。 |
| 1 数据质量 | 对齐 456/454、字段缺失、URL 粒度、日期类型与来源覆盖；获得原始标签/抽检材料后做按来源和主题分层的人工复核，记录分歧。 | `market/voc_quality_review.md` 与经核验的 `voc_sample_log_v2.csv`；没有原文/标签证据时明确降级，不伪称独立复核。 |
| 2 竞品证据 | 在 H1/H2/H3 下补六维同口径比较，一项主张一条来源；记录动态权益和价格的有效日。 | `market/competitor_claims.csv`、修订矩阵与 `competitor_notes.md`；保持 3+2，不做无依据总分。 |
| 3 市场与机制 | 将真实痛点、替代选择和 Duolingo 待测优势连到行为、学习、商业与成本；保留相反案例。 | 修订 `market_opportunity.md`，最多 3 条逻辑链和一页 `stage2_decision_memo.md`。 |
| 4 一次决策审阅 | 按下方 Gate 复核，交给 Stage 3/4/5，停止继续扩张研究范围。 | `STAGE_STATUS.md` 与 Stage Review：证据等级、实际检查、最大未知、下一行动。 |

`funnel.md` 中关于向数十万商店评论或更多 Reddit 帖子扩张的数字属于提供者外推，**不作为本阶段采集指令或通过条件**。本阶段优先修复直接相关性与来源质量；若这些不能修复，就降低结论等级并转入下一阶段。

## 5. Stage 2.1 Gate：做到什么程度才收束

1. **输入质量**：记录真实/未知的采集框、期间、来源许可、去重母体、直接相关分母与链接粒度；`samples.csv` 的 298 个标签至少经可追溯原文/标签材料抽核，或被明确降级为“提交者筛选的候选样本”。去重和日期冲突须对账，不能一边保留矛盾一边计算精度。
2. **竞品可比性**：H1/H2/H3 都有同一任务下的 Duolingo 与相关替代选择对照；六维只写有证据的格子。每项决策性主张能追到单条来源及适用地区、版本、时间，明确效果/成本/付费未知。
3. **市场洞察**：最多 3 条发现，每条完成“用户任务 → 替代选择 → Duolingo 待测机制 → 行为/学习指标 → 商业影响假设 → 成本/护栏 → 反例”。不能仅以更多营收或正负评论数作为商业价值。
4. **决策交接**：明确 H1/H2/H3 哪个先测，为什么，需哪些内部事件与对照组；对 Max、Super、有限免费试用的意义是**条件性**的。证据不足时，给出一个最关键缺口和降级结论，仍完成一次审阅后收束。

达到 Gate 即结束 Stage 2.1，不为凑千级样本或装满矩阵继续搜集。任何真实因果效果、续费增量和单位成本留给 Stage 4/5 的情景与实验；Stage 3 公司级趋势只提供背景，不替代功能效果。
