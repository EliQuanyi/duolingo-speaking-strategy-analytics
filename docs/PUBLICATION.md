## 什么公开，什么保留本地

| 文件类别 | 公开处理与理由 |
|---|---|
| 自行编写的分析代码、报告、Notebook、图表、审核与方法文档 | 在仓库保留；从首页按用途导航，不要求读者通读过程文档 |
| 官方必要事实、公开来源URL、自行概括的竞品观察、去标识聚合 | 保留原始来源和范围；行数、URL数和检查次数不充作用户样本数 |
| 正式冻结包及最小工程QA | 按显式白名单发布；CSV/代码起可复现，不承诺原网页采集或私人输入复现 |
| 历史v1经济演示与旧验证 | 保留可审计修正轨迹，并明确标为退役；不用于正式ROI、排行或数据包。当前模型只读取v2 |
| 用户提供的私人298条原始记录、原文采集、认证及本地自动化接入 | 保留本地，不进入仓库/发布资产；公开保留收到的聚合与采样边界 |
| 第三方全文、外部项目源码或完整评论集 | 不纳入发布范围；第三方链接可访问不代表有再分发许可 |

本项目尚未选择新的开源License。仓库公开供阅读和核查，不等于第三方资料或全部内容获得新的再使用许可。可选Stage2采集依赖保留各自原许可；未把第三方项目源码复制进本仓库。

## 验证与版本角色

`portfolio-v1.0`是面向招聘展示的发布版本；正式文稿仍标`final-v1.0`，整理入口为`closeout-v1.1`，量化为`stage4-v2.0`，实验设计为`stage5-v1.0`，数据包为清单中的v1.1。这些标签描述不同工件，不将新包装当成新的产品观测。

`.gitattributes`保留发布文件字节，避免Windows/Linux换行转换破坏已验收SHA-256；它不进行全仓库格式化。公开文件需在新的Git目录按复现指南复核；GitHub Actions只核标准库分析路径，不执行采集、Office、真人研究或内部实验。

最终验收的ZIP路径采用仓库相对路径，避免解压位置改变导致收据误报或暴露本机目录。历史运行记录的本机执行器路径仅用于环境说明，公开前会隐去个人目录，不改变已记录的执行状态或输出。

Stage4的README仅补齐已完成Stage5设计的状态；对应验收重新执行和登记。它不改变冻结经济输入、模型、CSV或原来源审核结论。工程验证不是来源真实性认证，更不是功能因果证明。
