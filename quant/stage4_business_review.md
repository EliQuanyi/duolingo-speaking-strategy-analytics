# Stage 4｜Speaking权益扩张：经济门槛与下一步决策

> **历史v1，已被 [Stage4最终交付v2](stage4_final_delivery.md) 替代。**以下作者情景结果退出正式商业论证，P1不再是预选试验；先确认真实增量与实施路线。原始快照见 [history/stage4_v1_business_review.md](history/stage4_v1_business_review.md)。

版本 stage4-v1.0｜资料截止与实际执行日：2026-10-02｜外部公开资料项目。

## 1. 给决策者的结论

**Stage4已完成条件性经济模型；实际经济性仍未识别。下一步先核资格，再优先设计H1/P1的小额增量Super验证，P2有限免费试用暂不全面扩张。**这一顺序来自市场任务证据、公司已推进Super的方向和可拆分的验证问题，不来自D情景中的“ROI赢家”。如果P0已给目标Super同样权益、找不到真实增量，P1不进入试验，回到明确的增量政策定义。

三个可用结论：

1. **有效使用、学习与净商业价值须分别证明。**H1有特定完成者短期学习信号；自然使用、迁移、计费与成本没有被它证明。市场证据决定先测谁，不能填付费概率。
2. **成本与套餐分流共同决定盈亏平衡，不能仅看转付费或调用增多。**模型已包含赠送后付费调用、对照原有成本、失败浪费和原Max层的独立分流；当前全部经济数值为D示例。
3. **无法给总体政策赢家，但能给可审核的条件和数据需求。**资格、净计费路径、账单工作量、固定费/规模与Max传播是具体缺口；未知权重不合并每千人结果。

## 4. 真正算出的是什么

经济输入无可校准事实，所有美元/路径概率/服务分钟均标D。三情景为低/基准/高反应强度，不是低/中/高预测置信区间。以下值来自本次真实执行的 [情景CSV](../data/public/scenario_results.csv) 和 [阈值CSV](../data/public/stage4_break_even.csv)。

| D演示分支 | 强度 | 净贡献/分配账户/90天（美元，D） | 盈亏平衡所需gain路径概率差（百分点，D） | 工程单价上界（美元/服务分钟，D） |
|---|---|---:|---:|---:|
| P1 / 原Super | low | +0.062450 | 1.3061 | 0.167775 |
| P1 / 原Super | base | −0.019260 | 4.2140 | 0.036318 |
| P1 / 原Super | high | −0.560336 | 14.2260 | 0.017903 |
| P2 / 原Free | low | −0.024895 | 0.7103 | −0.051400：无可行非负价格 |
| P2 / 原Free | base | +0.009740 | 1.4177 | 0.045392 |
| P2 / 原Free | high | −0.117232 | 3.9901 | 0.026338 |

这些概率差来自**完整计费路径的D边际构造**，不是实际续费率/转化率提升。不能用0.009740与−0.019260宣布P2更优，因为原层不同、权重未知，而且数值全为作者假设。

参考P1/Super：gain净边际贡献G=9美元，loss扣成本节省后的净损失L=11.2美元；赠送服务量5.4315分钟，k=0.04，D固定分摊f=0.05。因此 `g_min=(0.01×11.2+5.4315×0.04+0.05)/9=0.04214`。4.214个百分点是**这些假设下**的条件，不是Duolingo必须达到的真实门槛。账单实际贡献、工作量和F/N替换后门槛会改变。

参考P2/Free：g净边际贡献已扣后续付费调用成本，G=12−4×0.04=11.84；分流Max也减少成本，L=12−16×0.04=11.36。不能漏后续成本或把全部12/24美元当增量套餐收入。所需g约1.4177个百分点同样只是D条件。

**结构洞察**：提高采用可能同时提高成本；免费试用的升级次数不能单独评价经济性。本D例假设原Max降级路径调用较少，所以服务成本下降；实际降级者也可能多用，成本方向须验证。净损失必须包含两臂贡献与成本差，这是会计结算要求，不能把该要求当行为方向的证明。

## 5. 交给Stage5：一个优先验证问题

**先核资格，再优先设计H1/P1：相对P0给未覆盖的原Super有限Lily额度，是否增加自然条件下的有效自主表达，且没有不可接受的学习/课程挤出或成本？**这里只确定交接方向，正式随机化、primary定义、N/MDE、分析窗和Scale/Iterate/Stop由Stage5锁定；本阶段没有创建或执行实验。

建议行为primary候选：每原分配账户每周有效自主表达分钟，含零使用者。有效表达需预注册“可理解、自主、非朗读/复述”等规则，并用人工盲审校准日志，不能把转写词数当有效学习。功能有效分钟不等于全部语言练习净增量；课程挤出和延后未练任务必须另测。

| 先补什么 | 最低数据与口径 | 怎样改变模型/决策 |
|---|---|---|
| **资格与真正增量** | 分配前tier、课程、母语/市场、设备版本、个人方案、Lily资格/剩余额度/生效时间 | 无资格差就停止P1，不重复计算已开放用户 |
| **自然有效练习与全员学习** | 原组标记、曝光、首通/失败/全部尝试、自主表达盲审、零使用与未纳入原因、延后未练任务 | 判断H1机制是否值得继续；不能仅凭更高词数推进 |
| **双臂成本** | offer/非offer互斥标签，语音/token/重试/回退/账单，统一H；失败也结算 | 得到真实Δu、Δc，替代工程k假设，重算额度与成本门槛 |
| **全员净计费贡献** | 原分组完整账单路径、生效时间、退款、费用、续订机会与现金/确认口径 | 估计Δm而非仅看升级；年付未成熟部分保留缺口 |
| **原Max传播分流** | 原Max资格与信息曝光、政策/offer对照、完整路径/账单、分期或群组设计依据 | Super单层个体RCT不识别此效应；未另测前不宣称总体政策净值 |
| **规模与固定费用** | 真实可部署各层N及同一总体权重、增量F、容量/技术约束 | 才能讨论总体机会或固定费盈亏平衡；不从每千人直接外推 |

优先级依**阻塞关系**而定，不依据任意D扫描声称已测得哪个参数最敏感。资格为前置；成本与净计费共同决定经济符号；规模影响总体金额；Max传播影响完整商业判定。

更新规则：保留原D版本，新数据以来源/定义/时期登记；原分组保留零使用与退出者，进行缺测敏感度。**若同一计费箱两臂的价格、退款、购买时点或非赠送工作量不同，共享m/u假设失效，不能只换q/g/l：须改用双臂完整路径均值或直接全员Δm/Δc并重审。**若机制/学习不足，先Iterate或Stop；若机制有信号但经济区间跨零，继续限定验证；只有真实同口径经济条件、学习护栏和成本均满足预设规则，才讨论Scale。没有匹配baseline/方差时不承诺精确试验样本量。

- **对应总纲板块**：07 Opportunity Sizing、08 Strategy Design。
- **本阶段决策问题**：H1任务下何种贡献/成本/分流条件值得下一轮验证？
- **本阶段产物**：四项必交文件；配套权威JSON、逐参数账本、政策证据，共四张派生CSV、两图、执行/独立复核脚本和本复盘。
- **交接对象与下一行动**：模拟产品经理/实验分析师先核资格，再设计一个H1/P1优先试验；不声称企业已接收。
- **数据/图表版本**：D输入stage4-v1.0；公开来源截止2026-10-02；`run_stage4.py --execute-direct`生成，CSV/PNG字节及Notebook方法见机器记录。
- **Findings**：有效使用与经济性分开；成本/分流阈值共同决定净值；资格和真实参数未足够选赢家。
- **Evidence**：官方A（P供给属性）与既有受限学习/市场证据限定范围；全部经济值D；未知规模/权重/F保留空值。
- **Business meaning**：权益向低层开放必须衡量完整路径净贡献、后续调用与Max传播；不能只看升级和通话增加。
- **Decision impact**：不全面扩张P2；先核资格并验证H1/P1，条件不足则停止该政策分支；这是研究顺序非ROI排名。
- **Hypothesis status**：H1有受限短期学习信号，自然开口/迁移待测；H3经济净值待测，未被证伪或证明。
- **Unknowns / fallback**：权益/商业/成本/规模未知；条件阈值和D演示，禁止现实排序与实际Scale。
- **Checks actually run**：输入契约、fresh direct Notebook、独立Decimal复算/阈值代回/错误输入与边界、再执行一致性和两图视觉；各具体结果见机器记录，不把检查次数当独立证据。
- **Gate**：证据降级通过（政策事实可追溯、经济未实测）；业务通过（阈值/路径改变验证要求）；决策通过（资格前置/一优先问题及停止条件）；相关性通过（Speaking权益扩张）。
- **Scope cut**：无真实总体ROI、长期DAU/LTV预测、组合政策、新增VOC/竞品、正式Stage5实验或kernel反复修复。
- **Next stage input**：本报告、政策契约、参数、模型、四表、策略比较及机器审核；Stage5锁定可执行实验与条件性决策卡。
