# Stage 2.1 竞品证据准入与质量审阅规则

更新：2026-09-29。研究问题固定为 H1 日本中级英语开放对话、H2 美国初学西语引导通话、H3 日本英语有限试用。用户提交的 `samples.csv` 是 **Duolingo 用户态度**，不进入竞品样本数、竞品产品体验或跨产品满意度比较。

## 证据单位与准入

- **原子观察**：一项可核对的产品供给、真实体验或研究结果，对应一处来源定位。多个观察可来自同一 URL，但只算一个独立来源；同一作者多段体验只算一位体验者。
- **研究受访者去重与尝试口径**：论文中不同匿名编号可作为不同受访者，但同一论文仍只算一个研究来源；跨论文匿名身份不可绝对核验。仅见到入口、没有发起或交互记录的作者记 `context_only`，不计入目标功能体验者。已发起但因技术故障未完成的尝试保留为真实失败反例，**不算完成会话**。
- **产品特异性**：明确到 Speak、ELSA AI Roleplay、Babbel Speak、ChatGPT Voice 或 Preply 的相关功能。一般应用评分、普通发音题、整个品牌营收不当作 Video Call 同场景体验。
- **条件完整性**：记录目标语、用户水平、地区、设备、权益和版本中来源实际给出的部分；没有给出的写未知。动态权益写访问日期，旧公告不自动当现行供给。
- **账本字段**：V2 明列 `claim_id`、`dimension`、`hypothesis`、`region`、`language_level`、`tier`、`device_or_version`、`valid_as_of`、来源定位/时间、证据等级、独立单位与审阅状态。`unknown` 表示来源未交代，**不是**该地区或权益不可用；场景标签也不等于真实账户资格。
- **来源分层**：P 为提供方产品/权益说明，只证明其宣称的供给；B 为有样本、方法和结果边界的独立研究；C 为可定位的第一人称使用或独立实测，只能提示机制与反例；D 为分析假设，不列作观察。提供方内部效果研究单列，不能当独立研究。
- **排除**：无使用细节的聚合星级、营销改写、无方法的 SEO/联盟“评测”、疑似机器生成评论、跨版本拼接价格、未能定位原页的转述、与目标功能不符的产品研究、未经允许的批量平台采集。

## 数量与质量关

本轮目标是 **数十条到约百条高相关原子观察**，而非几千条。报告必须同时给出原子观察数、独立 URL 数、独立体验者数、独立研究数、按产品/场景的分布与被排除数量；不把同一页面拆行虚增“多源”。对每个产品至少有可核对的功能与权益供给、一个与场景直接相关的外部体验或明示缺口、一个反面解释。缺少外部体验时，该产品只作为供给对照，不能作用户偏好比较。

每个会改变 H1–H3 顺序的结论，至少由**两种不同性质的证据**支撑，例如产品页面 + 独立使用体验或研究；公司披露与自家博客仍属同一利益方。B 类研究必须写明是否测试**当前被比较的功能**，否则仅作机制类比。C 类体验不计算发生率，也不能与 Duolingo 自选评论做数量/情绪胜负。场景差异过大时明确退出直接比较。

## 审阅与停止

1. 对每个纳入来源打开原页，核对标题、主体、日期、定位和是否真实测试目标功能；抽核时记录无法打开或存在利益关系的条目。
2. 逐条将观察映射到 H1/H2/H3 的用户任务、六个商业维度与“供给 → 使用 → 学习 → 经营 → 成本”链上的**单一环节**；不能跨越未测环节。
3. 同一任务内保留反例、版本/地区限制与未测结果。实验优先级是条件性判断，不写跨产品总分或现有市场份额。
4. 当三条假设均可说明替代选择、决策性未知、试验指标与护栏，并完成一次 Stage Review，即停止搜索；未过关则降级结论并交给后续实机/内部实验，避免无限扩样。

三个公开平台采集工具的在线使用约束见 [`source_access_review.md`](source_access_review.md)。本轮主要使用可直接定位的官网、研究论文和人工阅读的公开独立体验；只保留改写后的观察与 URL，不批量复制原文评论。
