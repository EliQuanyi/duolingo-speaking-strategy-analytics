# Stage 2 市场与用户

本阶段已**降级通过**。入口为 [`market_opportunity.md`](market_opportunity.md)：包含需求分层、产品价值链、证据边界、H1–H3 和 Stage Review。主要结论是优先验证日本语母语的中级英语学习者能否自愿、持续完成有效口语练习；这是测试顺序，不是全面扩张决定。

- [`competitor_matrix.csv`](competitor_matrix.csv)、[`competitor_notes.md`](competitor_notes.md)：Duolingo 基准、3 个直接竞品及 2 个替代方案；只比较官方可核对的产品设计与交易摩擦。
- Stage 2.1 [`competitor_claims.csv`](competitor_claims.csv) 和 [`competitor_scenario_review.md`](competitor_scenario_review.md)：33 条逐主张官方来源，围绕 H1–H3 在六维同场景比较；提交的 298 条用户核查样本只用于设计质量/权益护栏，不做总体比例或跨产品效果排名。
- [`voc_analysis.md`](voc_analysis.md)、[`voc_sample_log.csv`](voc_sample_log.csv)、[`../data/public/voc_theme_summary.csv`](../data/public/voc_theme_summary.csv)：33 条去重公开样本的采样、匿名释义和可复算编码。其中直接涉及 Video Call 的 19 条均来自 Reddit，结论只用于生成假设。

公司级季度经营分析进入 Stage 3。缺失的自然使用、功能级留存、付费和 AI 成本仍需后续数据或实验验证。
