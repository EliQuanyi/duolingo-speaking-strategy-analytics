# Stage 2 市场与用户

Stage 2 与 Stage 2.1 均已**降级通过**。最新入口为 [`stage2_decision_memo.md`](stage2_decision_memo.md)：一次 Stage Review、H1–H3 的验证顺序及 Stage 3 交接。原 [`market_opportunity.md`](market_opportunity.md) 保留需求分层和产品价值链的 Stage 2 基线。主要结论是先验证日本语母语中级英语学习者能否自愿、持续完成有效口语练习；这是测试顺序，不是全面扩张决定。

- [`competitor_matrix.csv`](competitor_matrix.csv)、[`competitor_notes.md`](competitor_notes.md)：Duolingo 基准、3 个直接竞品及 2 个替代方案；只比较官方可核对的产品设计与交易摩擦。
- Stage 2.1 [`competitor_claims.csv`](competitor_claims.csv) 保留 Duolingo 基准与替代供给；[`competitor_evidence_v2.csv`](competitor_evidence_v2.csv) 另含三家直接竞品 97 条观察、48 个来源 URL，体验者去重、来源质量及排除理由见 [`competitor_evidence_quality_review.md`](competitor_evidence_quality_review.md)。[`competitor_scenario_review.md`](competitor_scenario_review.md) 按 H1–H3 六维同场景比较，不做总体满意度或效果排名。
- 用户提交的 298 条是**Duolingo 用户态度**，不算竞品数据；其真实性由用户确认，机械结构及无法独立复核的编码/分层问题见 [`voc_quality_review.md`](voc_quality_review.md)。
- [`voc_analysis.md`](voc_analysis.md)、[`voc_sample_log.csv`](voc_sample_log.csv)、[`../data/public/voc_theme_summary.csv`](../data/public/voc_theme_summary.csv)：33 条去重公开样本的采样、匿名释义和可复算编码。其中直接涉及 Video Call 的 19 条均来自 Reddit，结论只用于生成假设。

公司级季度经营分析进入 Stage 3。缺失的自然使用、功能级留存、付费和 AI 成本仍需后续数据或实验验证。

来源准入审查见 [`source_access_review.md`](source_access_review.md)。三个候选采集项目已在本地配置并完成离线检查；没有用它们进行在线批量试采。本轮竞品外部体验来自可定位公开页面的人工阅读与改写，质量状态和利益限制逐项保留。

Stage 2.1 按 [`../docs/STAGE2_REINFORCEMENT_STANDARD.md`](../docs/STAGE2_REINFORCEMENT_STANDARD.md) 收束；[`../docs/STAGE2_INPUT_INTAKE.md`](../docs/STAGE2_INPUT_INTAKE.md) 记录用户材料的来源确认和仍无法独立复算的采样/编码限制。
