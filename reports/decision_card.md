# 决策卡｜先验证 H1，自然迁移达标后再审扩张

**版本：stage5-v1.0｜证据截止：2026-10-02｜设计：2026-10-03｜身份：外部公开资料分析。**

**当前建议：核真实 P0、权益增量与实施路线；保留一项 H1 条件性试验预案。P1 尚未选定，执行未就绪，当前不批准 Scale。** 公开资料支持研究优先级，未证明盈利或真实经营 uplift。

| 决策要素 | 条件与行动 |
|---|---|
| 优先可检验问题 | 新增 Lily 访问能否在自然使用下改善日本市场、日语母语、中级英语用户的延后未练情境迁移？H1 任务优先不是 P1 政策预选。 |
| 公司分支 C1 | 仅当核实原 Super、iOS 个人账户确有未获 Lily 访问子集，且公司/合作方有权随机安排合法新增访问时点，才锁定“新增标准访问”一个增量。T 获审定权益，C 保持实际既有权益与购买路径；不创造次数、分钟或免费期。核实无增量则停止此定义。 |
| 唯一 primary | 延后未练情境口语迁移总分的全员、前测调整组间差。全部原分配账户含零使用、取消、切换和配置失败；失访不记零，不筛高频完成者。独立盲评、等难度平行任务与总分规则待校准冻结。 |
| 启动仍缺 | 当前资格/权益版本与权限；任务评分、学习/匹配续订成熟窗口；匹配方差、缺测、业务最小有意义增益及 N/MDE；课程/质量护栏；完整账单、服务成本和批准预算。当前均未核实，不用既有学习成绩或标价填缺口。 |
| Scale（未来规则） | primary 的 95% CI 下界达到预设有意义增益，合理缺测敏感度不翻转；课程挤出/质量通过；完整增量投入不超批准预算；权限与可外推总体通过。经营盈利准则另需完整双臂贡献/成本与匹配部署 N/F 达标；教学投资可按真实预算批准，但不称盈利。 |
| Iterate（未来规则） | 机制有信号但迁移未达门槛、精度不足或可修复测量问题；定位入口/质量/量表后重新冻结。不能删零使用者、换 primary 或用词数代替学习成功。 |
| Stop / 暂停（未来规则） | 无真实增量或合法对照则停止 C1；充分精度下效应上界仍低于最小有意义增益则停止当前处理的学习论证；课程/质量伤害、预算越界或配置/数据异常则暂停。宽区间不自动判零效果。 |
| 全政策限制 | 原 Super 单层试验不识别原 Max 传播/降级。未知层效果不设零；完整政策净值仍需同曝光各层效果、部署人数、真实新增固定费与传播设计。受限学习信号不能批准全公司扩张。 |
| 无公司权限 | 已获访问的知情参与者可做自然任务观察；随机鼓励估计邀请效果，同剂量工具比较估计规定剂量学习效果。三者与新增权益政策不同；外部结果不填公司收入/成本模型。无参与者或测量资源时停设计交接。 |

经济口径沿用 Stage4 v2：`Δv_s = (mean(m_T,s) − mean(m_C,s)) − (mean(c_T,s) − mean(c_C,s))`。m 扣退款/非 AI 费用，c 含对照已有成本、失败/重试/回退与购买后调用；全员差不再乘采用率。缺真实均值保持 `null`。

**模拟接收角色的下一步**：产品团队核真实增量及权限；教学/实验团队验证平行任务、全员随访并冻结 baseline/N/MDE/窗口；财务/数据团队对齐完整账单、服务成本、预算与经营准则。没有公司实际接收、审批、试验或上线。

依据与可复核入口：`quant/stage4_final_delivery.md`、`quant/evidence_assumptions.md`、`quant/stage4_gap_register.csv`；完整方案与方法来源见`experiments/test_plan.md`，字段契约见`experiments/event_spec.csv`，成品与检查见`experiments/stage5_final_validation.json`。本卡为条件规则，没有实验结果。
