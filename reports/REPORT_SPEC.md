# 商业决策报告交付规范（Stage 6）

**状态：Stage6正式报告11页，Word COM同版PDF已逐页检查；验收边界见`docs/FINAL_DELIVERY.md`。**面向产品与商业决策者，交付`reports/executive_decision_book.docx`与同版PDF；正文目标8–12页，方法与完整表另列。整份报告只回答`docs/DECISION_BRIEF.md`的主决策。

## 正文顺序

1. **执行摘要与建议**：一句话建议、优先试验、达到什么条件才扩大；说明证据强度。
2. **市场与用户**：目标用户、口语痛点、竞品/替代品差异；注明 VOC 样本与偏差。
3. **经营现状与趋势**：可比季度的 DAU、MAU/CURR、付费订阅、bookings/revenue 等可得指标；明确报告期和口径。
4. **Driver 与反证**：最多三个主要 Driver、产品推进时间线、至少一个替代解释；不将公司总量变化归因于 Video Call。
5. **机会与经济性**：优先来源约束的关键敏感度和盈亏平衡条件；Stage4 v2真实经济量未知时展示符号关系、就绪及缺口，不强造低/基准/高或数值预测。只有存在可核实参数域，才追加数值情景，事实与假设分列。
6. **方案、实验与决策**：最多三个方案的对比、一个优先对照试验、主要指标/护栏、Scale / Iterate / Stop 条件与下一行动。

## 图表与证据标准

- 正文至少包含一张**经营趋势图**、一张**市场或用户证据图/表**、一张**情景或敏感度图/表**，以及一张**方案比较表**；相同结论不重复作图。市场样本不足时改用证据表并标为探索性。
- 每张图写结论式标题、指标定义、时间与地域范围、单位、数据来源、计算口径及证据等级；真实值、管理层陈述与假设/情景用不同标记。
- 图表数据能追溯到 `data/public/` 的表或有说明的受限数据获取步骤，并能由分析代码/模型重新生成。正文只展示决策所需图表，详细表格与方法进附录。
- 趋势图显示可比基期与关键产品事件，但事件标记不代表因果；缺口、样本偏差和模型不确定性应在图旁说明。不要截断坐标轴制造夸大变化；配色之外还用文字或形状区分系列。
- 每个主要结论采用“**观察到什么 → 商业含义 → 对决策的影响**”三句式；来源脚注应直接指向原始文件、表格或页面。

## 报告验收

读者只看执行摘要就能说出建议与下一步；复核者能从任一关键数字追到数据、公式、来源；报告图表与数据包、量化模型的版本一致。PDF 的图、表、中文和来源链接需目视检查。没有内部实验结果时，实验只写成计划，监控只写成拟实施方案。
